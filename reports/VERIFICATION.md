## 막힌 검사와 수행하지 않은 작업

개발 환경은 Linux x86_64, Node **22.16.0**, npm **10.9.2**입니다. 실제 설치 대상은 `^22.19.0 || >=24.0.0`이며 Node 24를 권장합니다. 테스트 하네스가 22.16에서 통과했다고 native 의존성이 이 버전을 지원한다고 판단하지 않습니다.

npm 저장소 접근이 **EAI_AGAIN**으로 실패했습니다. 실제 의존성을 내려받거나 검증된 lockfile을 만들지 못했습니다. `npm run typecheck`를 실행했지만 **TS2688: Cannot find type definition file for 'node'**로 종료 코드 2가 반환되었습니다. 이는 타입 검사를 통과했다는 뜻이 아닙니다. 자세한 출력은 `sdk-typecheck-attempt.txt`에 있습니다.

따라서 다음은 미검증입니다: 설치된 실제 Paseo SDK와 플러그인 로더, 실제 Mixdog API/구독 계정 호출, native helper 실행, 실제 도구의 승인·거절, 휴대폰 LTE/5G 페어링·재접속, 사용자 서버의 systemd·재부팅. 별도 브랜드 Android/iOS 앱도 빌드하지 않았습니다. GitHub 저장소 생성·푸시·호스팅 CI 실행은 수행하지 않았습니다.

## 검증 의미

모의 모델을 사용한 프로세스 통합 테스트와 실제 모델 호출을 구분했습니다. 인터페이스 계약 검사는 지원하는 이벤트 부분집합의 검사이며 실제 SDK 컴파일을 대체하지 않습니다. 원본 Mixdog 소스는 특정 커밋 기준으로 확인했고 정책 연결부의 blob 해시를 테스트했지만 전체 프로그램이 실제 환경에서 동작한다고 확정하지 않습니다.

이번 결과로 토큰 절약률이나 비용 절감률을 산정하지 않았습니다. 자체 원격 프로토콜이나 완성 APK를 새로 만들었다고 주장하지 않습니다.
